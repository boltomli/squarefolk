# 文档地图

Squarefolk 的文档很少，但每份都权威。**冲突时的优先级：`core-spec.md`（可编码规格）> `design.md`（设计决策）> 其他一切**；发现两者矛盾请开 issue，不要自行取舍。

## 文档一览

| 文档 | 是什么 | 谁读 |
| --- | --- | --- |
| [../AGENTS.md](../AGENTS.md) | agent 与贡献者的约定与红线 | **所有人第一步** |
| [design.md](design.md) | 权威设计文档 v0.9：调研依据、所有机制与架构决策、待拍板清单 | 做任何设计/实现前按章节查 |

| [../CONTRIBUTING.md](../CONTRIBUTING.md) | 贡献流程、PR 清单、授权声明 | 提 PR 者 |
| [../LICENSE.md](../LICENSE.md) | CC BY-NC-SA 4.0 与非商业边界 | 分发/复用前必读 |

## 按角色的阅读路线

- **要动战斗代码**：AGENTS.md → design §3 → core-spec §4.1 → 黄金向量
- **要调数值**：design §4.2（TTR）→ §6.1 `dump` → §6.2 指标面板 → §9-D10
- **要做工具/编辑器**：design §5.1 → §6.3 → §6.1
- **要做发布/合规**：design §5.9 → §7 → §7.4
- **只想知道能不能开工**：design §9 —— 没标 ✅ 的都别做

- `design.md` 的改动必须同步顶部**修订记录**
- 引用一律用相对链接，避免绝对路径
